# Neonforge UI 设计参考

[English](neonforge-ui.md) | 中文

## 范围

Neonforge 是 DSH Web 工作台的视觉适配层。它保留 DSH 的运行时、会话事件、RPC、模块加载、插槽组合和插件能力，只改变视觉层级与组件呈现。

## 视觉方向

- 以深色控制室为主，加入克制的赛博朋克信号。
- 使用工业控制台层级，不做装饰性科幻仪表盘。
- 高对比色只用于操作、焦点和运行状态。
- 内容区保持安静，让流式对话成为视觉主角。
- 使用细轨道、折角、紧凑标签和少量硬边阴影。
- 装饰只使用 CSS，不增加素材或干扰指针输入。

## Token

| 角色 | Neonforge 值 | 用途 |
| --- | --- | --- |
| 画布 | `#080b10` | 应用背景与空白区域 |
| 表面 | `#111720` | 卡片、侧栏分组、输入框 |
| 抬升表面 | `#18212c` | hover、展开行、活动工具主体 |
| 边框 | `#2a3946` | 结构分隔线 |
| 主文字 | `#ecf5f2` | 对话与标题 |
| 次要文字 | `#8fa3a6` | 元信息与辅助文案 |
| 动作色 | `#c8ff3d` | 主操作、焦点、活动导航 |
| 信号色 | `#47e3d2` | 健康、完成、连接状态 |
| 警告色 | `#ffd166` | 等待与注意状态 |
| 危险色 | `#ff4f9a` | 错误、中断、破坏性操作 |
| 工具蓝 | `#5c76ff` | 硬边阴影与次级强调 |

间距以 4px 为基数，使用 8、12、16、24、32px 级别。普通控件使用 4 到 8px 圆角；折角只用于选中导航和主操作。硬边阴影使用 4 到 8px 偏移，不应用到每一张卡片。

## 外壳标准

现有 DSH `ui-layout` 继续负责三列网格和尺寸调整，Neonforge 只调整视觉层级：

- 侧边栏负责上下文、会话和导航，展开宽度目标为 232 到 272px。
- 中央区域负责对话和输入框，获得最多空间和最强内容对比度。
- 详情区负责运行与工具可观察性，可折叠。
- 分隔线使用 1px 结构线，不使用厚重投影。
- 标题可使用紧凑的全大写或等宽元信息标识模式和状态，但产品文案保持易读的中文。
- 窄屏继续使用现有收缩行为，不把三列压缩成不可读的轨道。

参考实现：[Boujoy Harness](https://github.com/asen-goat-mine/boujoy-harness)。

## 组件标准

- 导航选中态同时使用颜色与形状、偏移或边框变化。
- 状态同时通过文字和颜色信号表达空闲、运行、等待、成功和错误。
- 对话内容优先，工具调用和运行信息使用紧凑卡片或详情区承载。
- 输入框保持持续可发现，忙碌状态表达排队、中断或继续语义。
- 主按钮使用动作色填充和短硬边阴影，hover 与按下状态移动阴影而不是布局。
- `focus-visible` 轮廓使用动作色，并在所有表面保持可见。
- 动画短促且可选，减少动态偏好会关闭装饰性过渡和闪烁。
- 破坏性操作使用 danger token，并保留明确确认。

## DSH 适配映射

| DSH 区域 | Neonforge 处理 | 插件安全性 |
| --- | --- | --- |
| `ui-theme` token sheets | 增加限定作用域的主题层和语义别名 | 不改变插件行为或插槽 |
| `ui-layout` | 保留网格、尺寸调整和收缩语义，只重绘轨道和表面 | 不改变运行时或 store |
| `ui-sidebar` | 重绘导航、会话行和底部控件 | 保留现有 props 与动作 |
| `ui-conversation` | 重绘消息、工具、队列和输入框 | 保留会话对象层与插槽注册 |
| `ui-tool` / extensions | 使用共享语义别名和状态颜色 | 避免插件级全局选择器 |
| `ui-primitives` | 只在共享 primitive 拥有视觉职责时调整 | 检查广泛影响 |

## 插件隔离

Neonforge 通过现有 `ui-theme` 样式安装器叠加在基础主题之后。选择器限定在 `body[data-dsh-neonforge]` 或已有语义别名下，不依赖插件 ID、生成类名或无归属的 DOM 后代。

插件安装的 CSS 在满足以下任一条件时，不纳入视觉基线审计：

1. 样式表带有 `data-plugin` 标记，且不属于 DSH 主题所有者。
2. 选择器位于 Neonforge 作用域之外，且不消费 Neonforge 专属 token。
3. 规则属于适配映射中记录的共享 primitive 或平台 token。

未来插件不得使用全局 `body`、`:root` 或元素选择器进行视觉定制，应消费 `--dsw-*` 语义别名，或将 CSS Module 限定在自己的组件根节点。

## 验证

- 使用 `pnpm run build` 构建。
- 使用 `pnpm run test:gui` 验证客户端和宿主 GUI 包。
- 使用 `DSH_SNAPSHOT=replay pnpm run test:web` 验证组装后的浏览器输出。
- 在同一 checkout 中运行 `pnpm run dev:web` 和 `pnpm dsh web`，保持编译后的 shell 与插件 bundle 同步。
- 刷新 `http://127.0.0.1:3080` 检查三列布局、第三方插件隔离、键盘焦点、窄屏、流式状态、工具卡片、错误态和设置面板。
- 同时检查空状态、减少动态偏好和设置面板。
