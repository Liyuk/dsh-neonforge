# Agent Note: Neonforge 侧边栏视觉语言

Status: implemented

[English](2026-08-31-neonforge-sidebar-visual-language.md) | 中文

## 问题

Neonforge 之前已经处理工作区行和对话壳层，但侧边栏仍像未定制的 DSH 默认栏。参考设计依赖一条完整的视觉轨道：工业品牌牌、紧凑导航卡片、错位的文件夹/会话票据，以及小型系统遥测标识。补齐这些元素不能替换现有侧边栏槽位，也不能改变工作区和会话行为。

## 决定

侧边栏继续使用现有 `SidebarRoot` 与 `WorkspaceBrowser` 结构。稳定的 `data-neonforge-*` 标记分别标识侧栏壳、宽/收起模式、品牌行、品牌操作和页脚。主题负责呈现深色点阵轨道、带蓝色错位深度的酸绿色品牌牌、克制的导航卡片层次，以及 `SYS_ / VER.2.4.7` 页脚标识。运行时插件在装配已有宿主时应用等价标记，并在清理时移除全部标记。插件不复制导航、工作区或会话状态。

## 备选方案

- **用插件重新渲染一份侧边栏副本。** 拒绝：这会复制导航和工作区行为，使宿主更新与无障碍语义发生分叉。
- **把工业风位图作为必需资产。** 拒绝：仓库没有提供品牌牌或纹理资源；使用 CSS 几何和现有品牌槽位即可提供视觉提示，不引入虚构图片或新的资源流水线。
- **修改 AppFrame 网格宽度。** 拒绝：在现有列内即可接近参考效果，而改网格轨道会影响对话/详情布局与窄窗口行为。

## 后果

侧边栏获得独立的 Neonforge 身份，同时保留 DSH 的 DOM、槽位归属、键盘顺序，以及工作区/会话交互。视觉样式严格限定在 `body[data-dsh-neonforge]` 下；关闭或卸载插件会移除标记并恢复宿主主题。品牌 artwork 仍可通过现有 `sidebar.brand.*` 槽位替换。
